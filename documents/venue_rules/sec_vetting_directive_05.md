# SECURITY VETTING DIRECTIVE: CHECK-IN TIME BUFFERS
**Document ID:** SEC-VETTING-DIRECTIVE-05  
**Status:** Current / Authoritative  
**Effective Date:** 8 October 2026  
**Supersedes:** Standard Door Opening Schedule

To accommodate mandatory bag screening and digital identity verification, all events must incorporate a **15-minute check-in queue buffer** before official program sessions begin.

Doors must open 15 minutes earlier than the scheduled keynote or event start time to prevent lobby congestion.
