# Status: Current
# Effective Date: 1 September 2026

## Security Guard Ratios
- Security policy requires **at least 1 security guard per 50 attendees, rounded up** to the nearest whole integer.
- Example: For an attendance of 201, calculation is $\lceil 201 / 50 \rceil = 5$ guards minimum.
- Staffing cost per guard is standardized at **₹2,000 per shift** unless otherwise specified in event records. Security allocations must be explicitly synchronized with the security budget line.
